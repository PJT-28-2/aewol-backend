첨부한 반려동물 사진을 참고하여 모바일 앱 홈 화면에 사용할 귀여운 전신 3D 캐릭터를 만들어줘.

사진 속 반려동물의 실제 특징을 유지해줘.
- 동물 종류와 품종
- 털의 색상과 무늬
- 털의 길이와 질감
- 얼굴형과 주둥이
- 눈, 코, 귀의 모양
- 체형과 다리 길이
- 꼬리의 길이와 형태

실제 반려동물을 알아볼 수 있도록 주요 특징을 보존하면서, 귀엽고 둥근 모바일 앱용 3D 마스코트로 재해석해줘.

머리는 몸보다 약간 크게, 몸은 작고 통통하게 표현해줘. 표정은 밝고 사랑스럽게 만들되 사람 같은 얼굴이나 표정은 사용하지 마.

사진 속 털의 특성을 유지하면서 부드럽고 만질 수 있을 것 같은 고급스러운 3D 털 질감으로 표현해줘. 지나치게 실사적이지 않은 세련된 3D 캐릭터 렌더링으로 만들어줘.

반려동물이 네 발로 서 있는 자연스러운 3/4 방향 자세로 만들어줘. 카메라는 캐릭터의 눈높이보다 살짝 높은 위치에서 바라보게 해줘.

귀부터 발끝과 꼬리까지 전신이 완전히 보여야 해. 네 개의 다리와 모든 발이 자연스럽게 구분되어야 하며, 꼬리도 처음부터 끝까지 보여야 해.

배경은 채도가 아주 높은 순수한 초록색(#00FF00) 단색으로 균일하게 채워줘. 그라데이션, 무늬, 질감, 체크무늬, 격자 패턴을 절대 넣지 마. 배경 전체가 정확히 같은 색상값을 가진 완전한 평면이어야 해.

바닥, 타원, 원형 배경, 받침대, 원기둥, 발판, 그림자, 접지 그림자, 반사를 넣지 마. 캐릭터의 털색은 사진 원본 그대로 유지하고, 배경색이 캐릭터에 번지거나 반사되지 않게 해줘.

정사각형 캔버스에서 캐릭터를 중앙에 배치하고 사방에 충분한 투명 여백을 남겨줘. 머리, 귀, 발과 꼬리가 이미지 밖으로 잘리지 않게 해줘.

[필수 조건]
- 정확히 네 개의 다리와 네 개의 발
- 정확히 두 개의 귀와 한 개의 꼬리
- 깨끗하고 자연스러운 전신 실루엣
- 모든 신체 부위가 완전히 보이는 구도
- 캐릭터 이외의 모든 영역이 투명한 배경
- 모바일 UI의 작은 크기에서도 잘 보이는 단순한 형태
- 기존 캐릭터를 모방하지 않은 독창적인 디자인

[제외 요소]
텍스트, 글자, 로고, 워터마크, 목걸이, 옷, 모자, 액세서리, 장난감, 동전, 지갑, 상자, 바닥, 타원, 원, 받침대, 그림자, 사람의 손, 사람의 얼굴을 넣지 마.

다리나 발, 귀, 꼬리를 추가하거나 누락하지 말고, 뒤틀린 신체 구조, 합쳐진 다리, 부자연스러운 발, 잘린 신체 부위를 만들지 마.
